# Crocodile Hero Sprite Pack

Готовый набор спрайтов для Telegram Mini App.

## Содержимое

- `crocodile-hero-spritesheet.png` — прозрачный RGBA PNG, 1280×1280 px.
- Сетка — 4×4, размер одного кадра — 320×320 px.
- `frames/` — те же 16 кадров отдельными прозрачными PNG.
- `sprite-config.json` — номера кадров и рекомендуемая частота анимаций.

## Порядок анимаций

- Кадры 0–3: `idle` — покой/дыхание.
- Кадры 4–7: `run` — бег.
- Кадры 8–11: `jump` — приседание, отрыв, верхняя точка, падение.
- Кадры 12–15: `lie` — переход в положение лёжа и отдых.

## Подключение

Поместите папку в `public/assets/crocodile-hero/`. Если игра использует Canvas, Phaser, PixiJS или собственный игровой цикл, режьте лист на кадры 320×320 по строкам слева направо. Для DOM/CSS можно менять `background-position` с шагом 320 px.

Для отображения героя влево используйте горизонтальное отражение (`scaleX(-1)`), отдельные изображения не нужны.
